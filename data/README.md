# Data Directory Structure

This directory stores authentic datasets for the **HostelIQ** project under a two-tier data architecture:

- `data/raw/`: Dedicated repository for untouched, authentic government census datasets directly obtained from official sources (e.g., `aishe_hostel_data.csv`). Files in this directory are strictly immutable.
- `data/processed/`: Stores cleaned, validated, and state-harmonized analytical tables generated by reproducible R preprocessing scripts (e.g., `aishe_master.rds`).

## Academic & Ethical Data Governance
1. **Authentic Data Only:** In compliance with course standards and academic integrity directives, this project exclusively uses authentic census data from the **All India Survey on Higher Education (AISHE)**, Ministry of Education, Government of India.
2. **Zero Synthetic or Fabricated Data:** Synthetic, dummy, or artificially simulated observations are strictly prohibited and not used in this project.
3. **Zero Personally Identifiable Information (PII):** The AISHE dataset contains aggregated institutional census counts. No individual student names, contact numbers, email addresses, or personal records exist or are collected.
4. **Legal Licensing:** Governed under the **Government Open Data License - India (GODL)** and National Data Sharing and Accessibility Policy (NDSAP), authorizing academic research and educational publication with proper attribution.
